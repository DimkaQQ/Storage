# Проверка цен — мониторинг закупок ресторанов

Desktop-веб-приложение для контроля закупочных цен сети ресторанов. Реализует
техническое задание **«ТЗ проверка цен»**: сравнивает **плановую** цену из
матрицы сырья с **фактической** ценой закупки из отчётов iiko и показывает эффект
мониторинга по каждой точке и консолидированно.

## Что внутри

Данные извлечены из двух исходных таблиц (ТЗ + матрица «Сырьё F Алматы» с
отчётами о закупках iiko по 13 точкам, период — май 2026):

- **Обзор** — ключевые показатели: сумма закупок, чистый эффект мониторинга,
  переплаты и экономия, совпадение с матрицей, аномалии. Графики эффекта по
  ресторанам и структуры позиций.
- **Проверка цен** — ядро ТЗ. Таблица «план против факта» по каждой позиции:
  плановая цена, фактическая, отклонение %, денежный эффект, ABC-класс, статус.
  Поиск, фильтры по статусу, сортировка по любому столбцу, экспорт в CSV.
- **Рестораны** — карточки по каждой точке и сводная таблица. Любую точку можно
  смотреть отдельно или консолидированно (переключатель в шапке).
- **ABC-анализ** — классификация закупок A/B/C по вкладу в затраты, кривая
  Парето, фокус-таблица группы A (позиции, где контроль цен даёт максимум).
- **Аномалии** — сигнализация по ТЗ: позиции, которых нет в план-матрице, и
  расхождения единиц измерения (шт/кг) — для ручной проверки.

## Логика сравнения (`src/lib/data.ts`)

- **Факт (unit)** = сумма закупки ÷ количество из отчёта iiko.
- **План** = цена за единицу из матрицы (сопоставление по наименованию iiko).
- **Отклонение** = (факт − план) / план. Норма — в пределах ±2 %.
- **Эффект** = (план − факт) × количество: «+» экономия, «−» переплата.
- **Аномалия** — факт отличается от плана более чем в 3 раза (разные единицы
  измерения); исключается из денежного эффекта.
- **Фильтр ТЗ** — позиции с оборотом до 1000 ₸ не показываются.

## Запуск

```bash
npm install
npm run dev      # разработка (http://localhost:5173)
npm run build    # прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

Приложение рассчитано **только на десктоп** (ширина окна ≥ 1100 px).
